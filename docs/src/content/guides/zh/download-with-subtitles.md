bilibili视频除简体中文字幕外,常有UP主或观众添加的多语言字幕。把字幕一起保存,离线观看时也能使用播放器的字幕功能。本文介绍用免费应用[Bilibili Downloader GUI](/bilibili-downloader-gui/zh/)带字幕保存视频的方法。

## 软字幕与硬字幕的区别

字幕保存分两种模式,[Bilibili Downloader GUI](/bilibili-downloader-gui/zh/)均支持:

| 模式   | 原理                                              | 适合人群                             |
| ------ | ------------------------------------------------- | ------------------------------------ |
| 软字幕 | 字幕保存为独立文件(.srt等),播放器可开关、切换语言 | 想随时切换字幕的人、翻译用途         |
| 硬字幕 | 字幕压制进画面,任何设备都会显示                   | 手机、电视等不支持字幕文件的播放环境 |

当然也可以完全不带字幕下载。

## 操作步骤(应用内的字幕设置)

1. 启动应用,粘贴bilibili视频链接
2. 选画质的同时,选择字幕模式(软/硬/无)与语言
3. 开始下载,字幕先处理,再保存视频
4. 字幕处理进度会实时显示

**注意**:字幕下载需要通过Firefox登录bilibili。应用会自动检测Firefox的Cookie,只要事先在Firefox里登录过即可。登录详情见[视频下载方法指南](/bilibili-downloader-gui/zh/guides/how-to-download/)。

## 支持语言(最多15种)与AI字幕

bilibili视频可能带UP主或观众添加的多语言字幕,最多支持15种。人气越高的视频,字幕往往越全。

站内的**AI字幕(CC字幕)**同样支持:语音识别生成的中文字幕,可以和普通字幕一样保存、嵌入。

各视频可用语言不同。载入视频后,应用会列出该视频实际可用的字幕语言。

## 保存后的字幕文件在播放器中显示

软字幕模式下,字幕文件与视频保存在同一目录。

**VLC / mpv / MPC-HC等主流播放器**:字幕文件与视频同名且同目录时,打开视频即自动加载。也可在播放器的"加载字幕"菜单手动选择。

**手机观看**:使用支持外挂字幕的播放器(如VLC移动版),或在下载时直接选硬字幕以确保显示。

## 常见问题

### 选不了字幕/没有字幕?

该视频可能本身没有字幕,或未通过Firefox登录。请在Firefox登录bilibili后重试。

### 能保存中文字幕吗?

视频有注册中文字幕即可保存。没有的话,可能只有AI字幕可用。

### 软字幕和硬字幕选哪个?

手机、电视看选硬字幕;电脑播放器里想切换语言选软字幕。
