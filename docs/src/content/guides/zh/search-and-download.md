下载bilibili视频的传统流程是:在浏览器里找到视频→复制链接→粘贴到下载器。Bilibili Downloader GUI的**应用内搜索**把这个来回切换彻底省掉了——在应用里输入关键词就能找到视频,预览确认后直接下载,全程不用离开应用。

本文介绍应用内搜索的全部用法(关键词搜索、热门内容流、为你推荐、悬停预览、搜索历史),以及它与传统的URL粘贴如何选择。应用的安装与下载基础请先阅读[bilibili视频下载方法汇总](/bilibili-downloader-gui/zh/guides/how-to-download/)。

## 应用内搜索能做什么

应用内搜索直接调用与bilibili网站相同的数据源,包含三种用法:

- **关键词搜索**: 按视频标题、UP主名称查找,输入时实时显示搜索联想
- **热门内容流**: 搜索框为空时,展示bilibili全站热门视频(综合热门),无限滚动加载
- **为你推荐**: 登录后,由bilibili真实推荐引擎为你挑选的视频

将鼠标悬停在结果卡片上即可播放预览,看中的视频可以当场加入下载。

## 用关键词搜索视频

1. 启动应用,在搜索框输入关键词(如「VOCALOID」「原神 实况」)
2. 输入过程中会出现搜索候选,点击候选或直接按Enter搜索
3. 搜索结果以列表展示,持续滚动即可不断加载(无限滚动)

悬停卡片会播放短视频预览。找到想保存的视频后,点击卡片上的下载按钮,选择画质和字幕即可。画质上限取决于登录状态和会员等级,详见[下载方法指南](/bilibili-downloader-gui/zh/guides/how-to-download/)的画质部分。

批量保存时还有两个快捷键:**Ctrl+A**一键选择/取消当前视频的全部分P,**Ctrl+Enter**将所选内容直接送入下载队列。

## 用热门内容流掌握流行趋势

搜索框留空时,应用会展示bilibili全站正在热门的视频。没有明确目标、想「保存当下热门」或「找点好看的动画」时最为方便。

热门内容流同样支持滚动自动加载,每张卡片都能直接下载,与关键词搜索一致。

## 登录后专属的「为你推荐」

使用Firefox Cookie或二维码登录bilibili后,页面上方会出现**为你推荐**版块。它使用与bilibili网页版首页相同的推荐引擎(基于观看行为的真实个性化),以12张比常规更大的卡片展示为你挑选的视频。

每张卡片都带有推荐理由徽章(如「高点赞量」),一眼就能明白为什么被推荐。未登录或获取失败时,该版块不会显示。

版块上的刷新按钮可随时重新加载推荐,停留页面期间内容也不会过时。

登录方法请参考[下载方法指南](/bilibili-downloader-gui/zh/guides/how-to-download/)的登录部分。

## 下载前用预览确认

应用内搜索最大的优势是**保存前确认**:

- 悬停或点击卡片,视频内容即刻播放
- 无法播放或受地区限制的视频会提前显示专门提示
- 粘贴URL时也一样:点击视频页的分P缩略图,同样会以对话框打开预览

不再因为缩略图好看就下载到不想要的视频。

## 搜索历史与多关键词切换

搜索过的关键词会保留为历史,并反映在应用URL中——重新打开URL即可恢复搜索状态。多个关键词的结果会分别保留并可切换,回到「之前那个关键词的结果」只需一下点击。

## 应用内搜索和URL粘贴,该用哪个?

| 场景                   | 推荐方式                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------ |
| 已在浏览器打开目标视频 | URL粘贴                                                                              |
| 没有明确目标/想看热门  | 应用内搜索(热门内容流)                                                               |
| 知道要找的主题         | 应用内搜索(关键词)                                                                   |
| 想发现符合口味的内容   | 应用内搜索(登录+为你推荐)                                                            |
| 按话数批量保存番剧     | URL+批量下载([番剧指南](/bilibili-downloader-gui/zh/guides/download-bangumi-batch/)) |

无论哪种方式,下载后的处理(字幕嵌入、MP3提取、合并等)完全相同。

## 常见问题

### 使用搜索功能需要登录吗?

不需要。关键词搜索和热门内容流无需登录即可使用,仅「为你推荐」需要登录。

### 搜索到的视频无法下载

可能是地区限制(仅中国大陆)的内容,也可能是登录已过期。排查步骤请参考[常见问题页面](/bilibili-downloader-gui/zh/faq/)。

### 能搜索番剧吗?

目前搜索仅覆盖用户投稿视频(UGC)。番剧(动画、电视剧)请通过URL批量下载保存。
