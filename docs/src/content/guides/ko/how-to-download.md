bilibili(빌리빌리)는 중국 최대급 동영상 플랫폼으로 애니메이션, 음악, 게임, 강좌 등 방대한 콘텐츠를 보유하고 있습니다. 하지만 일반 사용자에게 오프라인 저장 기능을 거의 제공하지 않아, 오프라인 시청이나 소장을 원하면 다운로더가 필요합니다.

이 글에서는 2026년 현재 bilibili 동영상을 저장하는 방법을 데스크톱 앱, 온라인 도구, 모바일 앱의 세 가지 유형으로 나눠 설명합니다. 초보자 기준으로 모든 단계를 담았습니다.

## bilibili(빌리빌리)란?

2009년에 시작한 중국 동영상 공유 플랫폼으로, 화면을 가로지르는 탄막(댓글) 문화가 특징입니다. 애니메이션, 뱅구미(공식 라이선스 드라마·애니), 게임, 음악, 지식 콘텐츠가 주력입니다. 한국 사용자에게는 다른 곳에서 볼 수 없는 애니메이션이나 보컬로이드 음악의 출처로 활용도가 높습니다.

콘텐츠는 크게 세 종류입니다:

- **일반 업로드 영상(UGC)**: 사용자가 올린 동영상
- **뱅구미(번극)**: 공식 라이선스 애니·드라마. 회차 단위로 구성
- **강좌**: 유료/무료 강의형 콘텐츠. 여러 파트로 구성

세 가지 모두 다운로드 가능합니다. 단, 일부 콘텐츠는 중국 본토 한정 지역 제한이 있어 해외에서는 접근할 수 없습니다.

## 다운로드 전 주의: 저작권과 이용약관

다운로드는 **개인 시청 목적으로만** 허용됩니다. bilibili 이용약관과 저작권법을 준수하고 다음은 피하세요:

- 권리자 허락 없는 재업로드·재배포
- 저장한 유료 콘텐츠의 공유
- 저장 영상의 상업적 이용

이 가이드의 모든 방법은 "자기 시청용 오프라인 저장"을 전제로 합니다.

## 방법 1: 무료 앱 "Bilibili Downloader GUI" 사용(추천)

첫 번째는 이 글의 작성자가 개발한 무료 오픈소스 데스크톱 앱 **Bilibili Downloader GUI**입니다. Windows와 macOS를 지원하며, 광고 없이 가입 없이 사용할 수 있습니다. 소스 코드는 GitHub에 전부 공개되어 있습니다.

추천 이유:

- 완전 무료(광고·가입 없음)
- 최대 4K 화질 다운로드
- 최대 15개 언어 자막 삽입
- 뱅구미(애니메이션) 회차 선택·일괄 다운로드
- 음성만 저장(MP3 등)

### 설치(Windows / macOS)

1. [공식 사이트 다운로드 섹션](/bilibili-downloader-gui/ko/#download)에서 OS에 맞는 설치 파일을 받습니다
2. Windows는 설치 프로그램 실행, macOS는 dmg를 열어 응용 프로그램 폴더로 드래그합니다
3. 처음 실행 시 보안 확인이 나오면 허용 후 시작합니다

### 기본 절차: URL 붙여넣고 다운로드

1. 브라우저에서 저장할 bilibili 동영상 페이지를 열고 주소를 복사합니다
2. 앱에 URL을 붙여넣으면 동영상 정보(제목·화질·회차)가 표시됩니다
3. 원하는 화질을 선택하고 다운로드를 시작합니다
4. 완료된 파일은 설정에서 지정한 폴더(기본 Downloads)에 저장됩니다

영상과 음성은 자동으로 병합되어 추가 작업이 필요 없습니다.

### 화질 선택(480p~4K와 로그인의 관계)

사용 가능한 화질은 bilibili 로그인 상태와 멤버십 등급에 따라 다릅니다:

| 상태         | 사용 가능 화질                     |
| ------------ | ---------------------------------- |
| 비로그인     | 360p~480p                          |
| 로그인       | 최대 1080p                         |
| 대멤버(유료) | 1080p 고비트레이트, 1080p60fps, 4K |

고화질 저장을 원한다면 앱에서 bilibili 계정으로 로그인하세요.

### 자막과 함께 저장

자막은 "소프트 자막(별도 파일, 플레이어에서 전환)"과 "하드 자막(영상에 새김)" 두 모드를 지원하며 AI 생성 자막도 처리합니다. 최대 15개 언어 지원. 자세한 절차는 [자막 다운로드 가이드](/bilibili-downloader-gui/ko/guides/download-with-subtitles/)에서 설명합니다.

참고: 자막 다운로드에는 Firefox 로그인이 필요합니다.

### 로그인 방법(Firefox Cookie / QR 코드)

앱은 두 가지 로그인 방식을 지원합니다:

- **Firefox Cookie 자동 감지**: Firefox에서 bilibili에 로그인해 두면 별도 조작 불필요
- **QR 코드 로그인**: 앱에 표시된 QR 코드를 bilibili 모바일 앱으로 스캔

두 방식은 언제든 전환할 수 있습니다.

### 애니메이션(뱅구미) 일괄 다운로드

뱅구미는 회차를 선택해 일괄 다운로드할 수 있습니다. 강좌의 여러 파트도 동일하게 지원합니다. 자세한 내용은 [뱅구미 일괄 다운로드 가이드](/bilibili-downloader-gui/ko/guides/download-bangumi-batch/)를 참고하세요.

## 방법 2: 온라인 도구 사용(도구 A~B)

설치가 부담이라면 브라우저에 URL만 붙여넣어 저장하는 온라인 도구(도구 A, 도구 B)도 있습니다. 편하지만 제약이 큽니다:

- 무료 구간은 화질이 720p 이하로 제한되는 경우가 많음
- 광고와 가짜 다운로드 버튼이 있어 오류 클릭 위험
- 동영상 URL을 제3자 서버로 전송(프라이버시 고려 필요)
- 뱅구미 일괄 다운로드와 자막 삽입은 미지원이 대부분

한두 개를 저화질로 저장할 때만 쓸 만합니다. 지속적으로 사용한다면 데스크톱 앱이 편합니다. 유형별 비교는 [다운로더 추천 비교](/bilibili-downloader-gui/ko/guides/best-downloaders/)에서 확인하세요.

## 방법 3: 모바일 앱으로 저장

iPhone/Android에서는 bilibili 공식 앱이 일부 콘텐츠에 다운로드 기능을 제공하지만 범위가 제한적이고 앱 내 재생으로 한정됩니다. 서드파티 모바일 다운로더도 있지만 스토어 정책으로 자주 사라져 안정적인 선택이라 하기 어렵습니다.

PC가 있다면 데스크톱 앱으로 저장 후 폰으로 옮기는 편이 확실합니다.

## 다운로드 실패 시 해결

실패 원인은 대부분 다음 중 하나입니다:

1. **지역 제한**: 중국 본토 한정 콘텐츠. 가져올 수 없습니다
2. **URL 오류**: 동영상 페이지 URL이 맞는지, 홈이나 재생목록 URL은 아닌지 확인하세요
3. **로그인 만료**: 고화질이 안 나오거나 뱅구미가 실패하면 다시 로그인하세요
4. **네트워크 오류**: 자동 재시도됩니다. 계속 실패하면 시간을 두고 재시도하세요

그래도 안 되면 GitHub 저장소 Issues에 제보하면 개발자가 확인합니다.

## 자주 묻는 질문

### 스마트폰(iPhone/Android)에서 쓸 수 있나요?

아니요. Bilibili Downloader GUI는 Windows와 macOS용 데스크톱 앱입니다. 저장한 영상은 PC에서 폰으로 옮겨 시청할 수 있습니다.

### 안전한가요? 바이러스는 없나요?

네. 오픈소스로 소스 코드가 전부 공개되어 누구나 검증할 수 있고, 광고도 없습니다.

### 음성만 MP3로 저장할 수 있나요?

네. 영상에서 음성만 추출해 저장할 수 있습니다. 절차는 [MP3 저장 가이드](/bilibili-downloader-gui/ko/guides/download-mp3-audio/)에 있습니다.

## 정리

- **데스크톱 앱**(Bilibili Downloader GUI): 고화질·자막·일괄 다운로드를 모두 갖춘 선택
- **온라인 도구**: 설치 불필요하지만 제약 많음
- **모바일 앱**: 편하지만 불안정

무료 + 고화질 + 자막 + 일괄 다운로드를 원한다면 오픈소스 [Bilibili Downloader GUI](/bilibili-downloader-gui/ko/)가 첫 번째 후보입니다. 다른 도구와 비교하고 싶다면 [2026년 다운로더 추천 비교](/bilibili-downloader-gui/ko/guides/best-downloaders/)도 함께 보세요. 다른 궁금한 점은 [자주 묻는 질문](/bilibili-downloader-gui/ko/faq/)에서 확인하세요.
