bilibili 동영상을 다운로드하는 기존 방식은 "브라우저에서 영상 찾기 → URL 복사 → 다운로더에 붙여넣기"였습니다. Bilibili Downloader GUI의**앱 내 검색**은 이 왕복을 없앱니다. 앱에서 키워드만 입력하면 bilibili 동영상을 찾고, 미리보기로 확인하고, 그대로 다운로드까지 진행할 수 있습니다.

이 글에서는 앱 내 검색의 모든 기능(키워드 검색, 인기 피드, 맞춤 추천, 미리보기, 검색 기록)과 기존 URL 붙여넣기와의 선택 기준을 설명합니다. 앱 설치와 다운로드 기본은 먼저 [bilibili 다운로드 방법 총정리](/bilibili-downloader-gui/ko/guides/how-to-download/)를 참고하세요.

## 앱 내 검색으로 할 수 있는 일

앱 내 검색은 bilibili 웹사이트와 동일한 데이터를 앱에서 직접 조회합니다. 세 가지 사용법이 있습니다.

- **키워드 검색**: 영상 제목이나 업로더 이름으로 찾기. 입력 중 실시간 검색어 자동완성 제공
- **인기 피드**: 검색어가 없을 때 bilibili 전체 인기 동영상(综合热门)을 무한 스크롤로 표시
- **맞춤 추천**: 로그인 중에만, bilibili 추천 엔진이 골라준 영상 표시

결과 카드에 마우스를 올리면 미리보기가 재생되어, 원하는 영상만 그 자리에서 다운로드할 수 있습니다.

## 키워드로 영상 검색하기

1. 앱을 실행하고 검색창에 키워드(예: "VOCALOID", 게임 이름)를 입력합니다
2. 입력 중 추천 검색어가 나타나면 클릭하거나, 그대로 Enter를 누릅니다
3. 검색 결과가 목록으로 표시되고 스크롤할수록 계속 불러와집니다(무한 스크롤)

카드에 마우스를 올리면 짧은 미리보기가 재생됩니다. 마음에 드는 영상은 카드의 다운로드 버튼으로 화질과 자막을 선택해 저장하세요. 화질 상한은 로그인 상태와 회원 등급에 따라 다르므로 [다운로드 방법 가이드](/bilibili-downloader-gui/ko/guides/how-to-download/)의 화질 부분을 참고하세요.

일괄 저장에는 키보드 단축키도 편리합니다. **Ctrl+A**로 불러온 동영상의 전체 파트를 선택/해제하고, **Ctrl+Enter**로 선택한 항목을 그대로 다운로드 대기열로 보낼 수 있습니다.

## 인기 피드로 트렌드 확인하기

검색창을 비워 두면 bilibili 전체에서 지금 인기 있는 영상이 표시됩니다. 특정 영상을 정하지 않고 "요즘 유행하는 것을 저장하고 싶다", "볼 만한 애니메이션을 찾고 싶다" 할 때 편리합니다.

인기 피드도 스크롤로 자동 로드되며, 모든 카드에서 키워드 검색과 동일하게 바로 다운로드할 수 있습니다.

## 로그인 중에만 보이는 '당신을 위한 추천'

Firefox 쿠키 또는 QR 코드로 bilibili에 로그인하면 화면 상단에 **당신을 위한 추천** 코너가 나타납니다. bilibili 웹 홈과 동일한 추천 엔진(시청 기반 진짜 개인화)으로, 회원님을 위해 선별된 영상 12개를 평소보다 큰 카드로 보여줍니다.

각 카드에는 추천 이유 배지(예: "高点赞量", 좋아요 많음)가 붙어 왜 추천됐는지 한눈에 알 수 있습니다. 미로그인이거나 가져오기에 실패하면 이 코너는 표시되지 않습니다.

코너의 새로 고침 버튼을 누르면 언제든 추천을 다시 불러옵니다. 화면을 보는 동안 내용이 오래되지 않습니다.

로그인 방법은 [다운로드 방법 가이드](/bilibili-downloader-gui/ko/guides/how-to-download/)의 로그인 부분에서 안내합니다.

## 다운로드 전에 미리보기로 확인

앱 내 검색의 최대 장점은 **저장 전 확인**입니다.

- 카드에 마우스를 올리거나 탭하면 영상이 바로 재생됩니다
- 재생할 수 없거나 지역 제한이 있는 영상은 전용 메시지로 미리 알 수 있습니다
- URL을 붙여넣은 경우에도, 동영상 페이지의 파트 썸네일을 클릭하면 같은 미리보기가 대화상자로 열립니다

썸네일만 보고 다운로드했다가 낭비하는 일이 없어집니다.

## 검색 기록과 여러 키워드 전환

검색한 키워드는 기록으로 남고 앱 URL에 반영됩니다. URL을 다시 열면(또는 화면을 공유하면) 검색 상태부터 재개됩니다. 여러 키워드의 결과도 각각 쌓여 전환할 수 있어 "아까 그 키워드 결과"로 한 번에 돌아갈 수 있습니다.

## 앱 내 검색과 URL 붙여넣기, 무엇을 쓸까?

| 상황                                 | 추천 방법                                                                                          |
| ------------------------------------ | -------------------------------------------------------------------------------------------------- |
| 이미 브라우저에서 영상을 열어둔 경우 | URL 붙여넣기                                                                                       |
| 정해진 목표 없음/트렌드 확인         | 앱 내 검색(인기 피드)                                                                              |
| 찾으려는 주제가 있는 경우            | 앱 내 검색(키워드)                                                                                 |
| 취향에 맞는 콘텐츠 발굴              | 앱 내 검색(로그인+맞춤 추천)                                                                       |
| 애니메이션 시즌 단위 일괄 저장       | URL+일괄 다운로드([애니메이션 가이드](/bilibili-downloader-gui/ko/guides/download-bangumi-batch/)) |

어느 방법이든 다운로드 후 처리(자막 삽입, MP3 추출, 병합 등)는 동일합니다.

## 자주 묻는 질문

### 검색 기능에 로그인이 필요한가요?

아니요. 키워드 검색과 인기 피드는 로그인 없이 사용할 수 있습니다. '당신을 위한 추천'만 로그인이 필요합니다.

### 검색 결과의 영상이 다운로드되지 않아요

지역 제한(중국 본토 한정) 콘텐츠이거나 로그인이 만료되었을 수 있습니다. 해결 단계는 [FAQ 페이지](/bilibili-downloader-gui/ko/faq/)를 참고하세요.

### 애니메이션도 검색할 수 있나요?

현재 검색은 사용자 업로드 영상(UGC)만 지원합니다. 애니메이션(번극)은 URL 일괄 다운로드로 저장하세요.

## 정리

Bilibili Downloader GUI의 앱 내 검색은 "찾기 → 확인 → 저장"을 하나의 앱에서 끝냅니다.

- URL 복사 없는 **키워드 검색**(자동완성+무한 스크롤)
- 트렌드를 파악하는 **인기 피드**
- 로그인 시 추천 이유 배지가 붙은 **맞춤 추천**
- 정말 원하는 것만 저장하는 **미리보기**

먼저 [bilibili 다운로드 방법 총정리](/bilibili-downloader-gui/ko/guides/how-to-download/)로 앱을 설치하고, 검색창에 좋아하는 키워드를 입력해 보세요.
