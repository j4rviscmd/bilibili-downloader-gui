bilibili 동영상에는 중국어 자막뿐 아니라 업로더나 시청자가 추가한 다국어 자막이 있는 경우가 많습니다. 자막을 함께 저장하면 오프라인 시청에도 플레이어의 자막 기능을 쓸 수 있어 편리합니다. 이 글에서는 무료 앱 [Bilibili Downloader GUI](/bilibili-downloader-gui/ko/)로 자막과 함께 동영상을 저장하는 방법을 설명합니다.

## 소프트 자막과 하드 자막의 차이

자막 저장에는 두 가지 모드가 있으며 [Bilibili Downloader GUI](/bilibili-downloader-gui/ko/)는 둘 다 지원합니다.

| 모드        | 방식                                                                    | 추천 대상                                     |
| ----------- | ----------------------------------------------------------------------- | --------------------------------------------- |
| 소프트 자막 | 자막을 별도 파일(.srt 등)로 저장. 플레이어에서 켜고 끄고 언어 전환 가능 | 자막을 나중에 전환하고 싶은 사람, 번역 용도   |
| 하드 자막   | 자막을 영상에 새김. 어떤 환경에서도 항상 표시                           | 자막 파일을 지원하지 않는 폰·TV에서 보는 사람 |

자막 없이 일반 다운로드도 물론 가능합니다.

## 절차(앱 내 자막 설정)

1. 앱을 실행하고 bilibili 동영상 URL을 붙여넣습니다
2. 화질과 함께 자막 모드(소프트/하드/없음)와 언어를 선택합니다
3. 다운로드를 시작하면 자막이 먼저 처리된 뒤 저장됩니다
4. 자막 처리 진행 상황이 실시간으로 표시됩니다

**주의**: 자막 다운로드에는 Firefox로 bilibili에 로그인해야 합니다. 앱이 Firefox 쿠키를 자동 감지하므로, Firefox에서 미리 로그인해 두면 별도 조작이 필요 없습니다. 로그인 절차는 [다운로드 방법 가이드](/bilibili-downloader-gui/ko/guides/how-to-download/)를 참고하세요.

## 지원 언어(최대 15개)와 AI 자막

bilibili 동영상에는 커뮤니티가 추가한 다국어 자막이 있을 수 있으며 최대 15개 언어를 지원합니다. 인기 있는 영상일수록 자막이 풍부한 경향이 있습니다.

또한 bilibili가 자동 생성하는 **AI 자막(CC 자막)**도 지원합니다. 음성 인식으로 만들어진 중국어 자막을 일반 자막과 같은 방식으로 저장·삽입할 수 있습니다.

지원 언어는 영상마다 다릅니다. 영상을 불러오면 해당 영상에서 실제 사용 가능한 자막 언어가 표시됩니다.

## 저장한 자막 파일을 플레이어에서 표시하기

소프트 자막으로 저장하면 자막 파일이 영상과 같은 폴더에 저장됩니다.

**VLC / mpv / MPC-HC 등 주요 플레이어**: 자막 파일이 같은 폴더에 같은 파일명으로 있으면 영상을 열 때 자동으로 로드됩니다. 수동으로는 플레이어의 "자막 트랙 추가" 메뉴에서 파일을 선택하면 됩니다.

**스마트폰 시청**: 외부 자막 파일을 열 수 있는 플레이어 앱(예: VLC for mobile)을 쓰거나, 확실하게 표시하려면 다운로드 시 하드 자막을 선택하세요.

## 자주 묻는 질문

### 자막을 선택할 수 없거나 표시되지 않아요

해당 영상에 자막이 아예 없거나, Firefox로 로그인하지 않은 경우일 수 있습니다. Firefox에서 bilibili에 로그인한 뒤 다시 시도하세요.

### 한국어 자막도 저장할 수 있나요?

영상에 한국어 자막이 등록되어 있으면 저장 가능합니다. 없는 영상에서는 AI 자막(중국어)만 사용할 수 있는 경우가 있습니다.

### 하드와 소프트 중 뭘 고르나요?

폰·TV에서 볼 거면 하드 자막, PC 플레이어에서 언어를 전환하고 싶으면 소프트 자막이 좋습니다.

## 정리

- 자막 저장은 소프트(별도 파일)와 하드(삽입) 두 모드
- [Bilibili Downloader GUI](/bilibili-downloader-gui/ko/)는 최대 15개 언어와 AI 자막 지원, 무료
- 자막 다운로드에는 Firefox 로그인 필요

자막이 필요 없다면 [다운로드 방법 가이드](/bilibili-downloader-gui/ko/guides/how-to-download/)를, 도구 선택이 고민이면 [다운로더 추천 비교](/bilibili-downloader-gui/ko/guides/best-downloaders/)를 참고하세요.
