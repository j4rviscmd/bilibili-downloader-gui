"bilibili 다운로더"를 검색하면 유료 소프트웨어 홍보 글이 가득합니다. 이 글은 그런 광고가 아닙니다. 이 글의 작성자가 개발한 무료 오픈소스 앱을 포함해 각 유형의 실상을 공정하게 비교합니다.

분쟁 방지를 위해 경쟁 제품은 **"도구 A", "도구 B"** 등 이니셜로 표기하고, 유형과 일반적인 특징만 설명합니다.

## 선택 기준

다운로더를 고르기 전 확인할 5가지:

1. **안전성**: 광고·가짜 다운로드 버튼 여부. 오픈소스는 누구나 코드 검증 가능
2. **가격**: 진짜 무료인가, 구독/일회성 결제인가? "무료 체험"은 화질 제한이 붙기 쉬움
3. **화질**: 480p뿐인가, 1080p/4K까지 되는가? (화질은 로그인 상태에도 좌우됨)
4. **자막**: 자막 저장·삽입 지원 여부. 지원하는 다운로더는 드묾
5. **일괄 다운로드**: 뱅구미 회차 선택·일괄 저장 가능 여부

## 데스크톱 앱(추천)

### Bilibili Downloader GUI(이 글의 작성자 개발·무료·오픈소스)

Windows·macOS용 오픈소스 다운로더. bilibili 전용으로 만들어져 뱅구미 시즌과 다중 파트 강좌 구조를 제대로 이해합니다.

**장점**

- 완전 무료·광고 없음·가입 불필요. 소스 코드는 [GitHub](https://github.com/j4rviscmd/bilibili-downloader-gui) 전체 공개
- 로그인 시 최대 4K, 자막은 최대 15개 언어 소프트/하드 삽입
- 뱅구미 회차 선택·일괄 다운로드, 음성만 MP3 저장
- Firefox Cookie/QR 코드 로그인으로 1080p 이상 해제

**단점**

- URL 기반: 앱 내 검색이 아니라 링크를 붙여넣어야 함
- 중국 본토 한정 지역 제한 콘텐츠는 가져올 수 없음

사용법은 [다운로드 방법 가이드](/bilibili-downloader-gui/ko/guides/how-to-download/)에서 단계별 설명합니다.

### 도구 A(상용 종합 다운로더)

다수의 동영상 사이트를 지원하는 범용 다운로더입니다.

**장점**: 지원 사이트가 매우 많음, 초보자도 쓰기 쉬운 UI.
**단점**: 유용한 기능은 구독 중심. bilibili 자막 삽입 지원은 제한적.

### 도구 B(일회성 결제 다운로더)

한 번 사면 계속 쓰는 방식.

**장점**: 계속 비용 없음, 일괄 다운로드 지원.
**단점**: 초기 비용 부담, 업데이트 중단 위험, 자막 삽입 미지원이 일반적.

## 온라인 도구(설치 불필요)

### 도구 D·E·F(브라우저 기반)

URL 붙여넣고 파일 받는 웹 서비스. 편의성은 최고지만 공통 약점이 있습니다:

- **화질 제한**: 무료는 480p~720p가 대부분
- **광고**: 가짜 다운로드 버튼이 흔하고 수상한 소프트웨어로 유도하기도 함
- **프라이버시**: 보는 영상의 URL을 제3자 서버로 전송
- **기능 부족**: 뱅구미 일괄 다운로드·자막 삽입은 사실상 불가

한두 개 저화질 저장용으로만 추천합니다.

## 모바일 앱

### 도구 G·H(모바일 다운로더)

도구 G는 무료+광고, 도구 H는 유료. 모바일 다운로더는 플랫폼 정책이나 bilibili 사이트 변경으로 갑자기 사라지는 일이 잦아 안정성이 가장 낮습니다. 자막 삽입과 뱅구미 일괄 다운로드도 대부분 미지원입니다.

PC에서 받아 폰으로 옮기는 편이 보통 더 편합니다.
