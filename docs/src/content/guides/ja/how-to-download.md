bilibili(ビリビリ)は中国最大級の動画共有サービスで、アニメ、音楽、ゲーム実況、講座など豊富なコンテンツが配信されています。しかし、公式には動画ファイルを手元に保存する機能が一般ユーザーにはほとんど提供されておらず、「オフラインで見返したい」「通信量を気にせず視聴したい」という目的には downloader(ダウンローダー)が必要です。

この記事では、2026年時点でbilibili動画をダウンロード・保存する方法を、無料のデスクトップアプリ、オンラインツール、モバイルアプリの3タイプに分けて解説します。初心者向けに、インストールから画質・字幕の設定まで手順ごとに説明します。

## bilibili(ビリビリ)とは?

bilibiliは2009年に開始した中国の動画共有プラットフォームです。ニコニコ動画と同じ「画面上にコメントが流れる」仕組みで、アニメ・番劇(ドラマ・アニメの公式配信)・ゲーム・音楽・知識系コンテンツが主力です。日本のユーザーには、中国語圏のみで配信されるアニメや、VOCALOID楽曲の保存先として利用者が多くいます。

動画の種類は大きく分けて3つあります。

- **ユーザー投稿動画(UGC)**: 一般ユーザーが投稿した動画
- **番劇(bangumi)**: アニメ・ドラマなどの公式配信コンテンツ。多くは話数単位で構成される
- **課程(コース)**: 講座形式の有料・無料コンテンツ。複数パートに分かれる

いずれも、対応したダウンローダーなら保存可能です。ただし一部コンテンツには地域制限(中国国内のみ視聴可)があり、日本からはアクセスできないものがあります。

## ダウンロード前の注意:著作権と利用規約

ダウンロードは**個人的な視聴目的に限る**のが原則です。bilibiliの利用規約と著作権法を遵守し、以下は避けてください。

- 権利者の許可なく動画を再投稿・再配布すること
- 有料コンテンツを保存して第三者に共有すること
- 保存した動画を商用利用すること

再配布や商用利用は違法ダウンロードの範疇に入りえます。本記事で紹介する方法は、すべて「自分が視聴するためのオフライン保存」を前提としています。

## 方法1:無料アプリ「Bilibili Downloader GUI」を使う(おすすめ)

まず紹介するのは、この記事の執筆者が開発している無料・オープンソースのデスクトップアプリ**Bilibili Downloader GUI**です。WindowsとmacOSに対応し、広告なし・登録なしで使えます。ソースコードはGitHubで全て公開されています。

おすすめの理由:

- 完全無料(広告・会員登録なし)
- 最大4Kまでの高画質ダウンロード
- 最大15言語の字幕を動画に埋め込み可能
- 番劇(アニメ)の話数選択・一括ダウンロードに対応
- 音声のみの保存(MP3等)も可能

### インストール(Windows / macOS)

1. [公式サイトのダウンロードセクション](/bilibili-downloader-gui/ja/#download)から、お使いのOS用のインストーラーを取得します
2. Windowsはインストーラーを実行、macOSはdmgを開いてアプリケーションフォルダにドラッグします
3. 初回起動時にOSのセキュリティ確認が表示されたら、許可して起動します

### 基本の手順:URLを貼ってダウンロード

1. ブラウザでbilibiliのダウンロードしたい動画ページを開き、アドレスバーのURLをコピーします
2. アプリにURLを貼り付けると、動画情報(タイトル・画質・話数)が表示されます
3. 保存したい画質を選び、ダウンロードを開始します
4. 完了した動画は設定画面で指定した保存先フォルダ(デフォルトはDownloads)に保存されます

動画と音声は自動で結合(マージ)されるため、追加作業は不要です。

### 画質の選び方(480p〜4Kとログインの関係)

利用できる画質は、bilibili側のログイン状態と会員ランクで変わります。

| 状態             | 利用可能な画質                      |
| ---------------- | ----------------------------------- |
| ログインなし     | 360p〜480p                          |
| ログイン済み     | 最大1080p                           |
| 大会員(有料会員) | 1080p高ビットレート、1080p60fps、4K |

高画質で保存したい場合は、事前にアプリ内でbilibiliアカウントにログインしてください。

### 字幕を付けて保存する

字幕は「ソフト字幕(プレイヤーで切り替え可能な別ファイル)」と「ハード字幕(動画に焼き付ける)」の2モードに対応し、AI生成字幕も処理できます。対応言語は最大15言語。詳しい手順は[字幕付きダウンロードのガイド](/bilibili-downloader-gui/ja/guides/download-with-subtitles/)で解説しています。

なお、字幕のダウンロードにはFirefoxでのログインが必要です。

### ログイン方法(Firefox Cookie / QRコード)

アプリは2つのログイン方法に対応しています。

- **Firefox Cookie自動検出**: Firefoxでbilibiliにログインしておけば手動操作なし
- **QRコードログイン**: アプリ内に表示されるQRコードをbilibiliモバイルアプリでスキャン

2つの方法はいつでも切り替えられます。

### アニメ(番劇)を一括ダウンロード

番劇は話数を選んで一括ダウンロードできます。講座(コース)の複数パートにも対応。詳しくは[番劇の一括ダウンロードガイド](/bilibili-downloader-gui/ja/guides/download-bangumi-batch/)を参照してください。

## 方法2:オンラインツールを使う(ツールA〜B)

インストールしたくない人には、ブラウザでURLを貼るだけで動画を取得できるオンラインツール(ツールA・ツールBと呼びます)もあります。手軽な反面、次の制約があります。

- 無料プランでは画質が制限されることが多い(720p以下など)
- ページ内広告や偽ダウンロードボタンが設置されていることがある
- 動画URLを第三者サーバーに送信するため、プライバシー面の考慮が必要
- 番劇の一括ダウンロードや字幕埋め込みには非対応のことが多い

数本だけ保存したい・最高画質を求めない、という場合には選択肢になります。継続して使うならデスクトップアプリが快適です。タイプ別の詳しい比較は[bilibiliダウンローダーおすすめ比較](/bilibili-downloader-gui/ja/guides/best-downloaders/)をご覧ください。

## 方法3:モバイルアプリで保存する

iPhone・Androidでは、bilibili公式アプリの一部コンテンツにダウンロード機能がありますが、対応作品が限られ、アプリ内での再生に限定されます。サードパーティ製のモバイル用ダウンローダーも存在しますが、ストアの規約で削除されることが多く、安定した選択肢とは言い難いのが実情です。

PCを持っているなら、デスクトップアプリで保存した動画をスマホに転送する方が確実です。

## ダウンロードできない時の対処法

保存に失敗する場合、原因の多くは次のいずれかです。

1. **地域制限**: 中国国内限定のコンテンツ。アプリからは取得できません
2. **URLの誤り**: 動画ページのURLではなく、再生リストやトップページのURLを貼っていないか確認してください
3. **ログイン切れ**: 高画質が選べない・番劇が取得できない場合はログインし直してください
4. **ネットワークエラー**: アプリは自動でリトライしますが、失敗が続く場合は時間を置いて再実行してください

それでも解決しない場合は、GitHubリポジトリのIssuesで報告すると開発者が確認できます。

### スマホ(iPhone/Android)では使えますか?

いいえ、Bilibili Downloader GUIはWindowsとmacOS向けのデスクトップアプリです。保存した動画はPCからスマホへ転送して視聴できます。

### 安全に使えますか?ウイルスはありませんか?

はい。オープンソースでソースコードが全て公開されており、誰でも内容を確認できます。広告も同梱されていません。

### 音声だけをMP3で保存できますか?

はい。動画から音声のみを抽出して保存できます。手順は[MP3保存ガイド](/bilibili-downloader-gui/ja/guides/download-mp3-audio/)で解説しています。
