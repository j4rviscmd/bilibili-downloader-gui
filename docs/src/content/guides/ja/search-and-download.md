bilibiliの動画をダウンロードするとき、これまでは「ブラウザで動画を探す→URLをコピー→アプリに貼り付け」という手順が定番でした。Bilibili Downloader GUIの**アプリ内検索**を使えば、この行き来が不要になります。アプリの中でキーワードを入力するだけでbilibiliの動画を探し、プレビューで確認し、そのままダウンロードまで進められます。

この記事では、アプリ内検索の使い方(キーワード検索・人気フィード・あなたへのおすすめ・プレビュー再生・検索履歴)と、従来のURL貼り付けとの使い分けまで解説します。アプリの基本のインストール手順は[bilibili動画のダウンロード方法まとめ](/bilibili-downloader-gui/ja/guides/how-to-download/)を先に参照してください。

## アプリ内検索でできること

アプリ内検索は、bilibiliのWebサイトと同じ情報源にアプリから直接アクセスする機能です。次の3つの使い方ができます。

- **キーワード検索**: 動画タイトルや投稿者名で探す。入力中はサジェスト(候補)も表示されます
- **人気フィード**: 何も入力しないときはbilibili全体の人気動画(综合热门)が無限スクロールで表示されます
- **あなたへのおすすめ**: ログイン中のみ、bilibiliのレコメンドエンジンがあなた向けに選んだ動画が表示されます

検索結果のカードにカーソルを合わせると動画のプレビューが再生され、「これは欲しい」というものだけをその場でダウンロードに回せます。

## キーワードで動画を検索する

1. アプリを起動し、検索ボックスにキーワード(例: 「VOCALOID」「原神 実況」)を入力します
2. 入力中に検索候補が表示されるので、目的のものがあればクリック、なければそのままEnterを押します
3. 検索結果が一覧表示され、スクロールするだけで次々に読み込まれます(無限スクロール)

検索結果からダウンロードしたい動画のカードにカーソルを合わせると、プレビューが再生されます。気に入ったらカードのダウンロードボタンから、画質と字幕を選んで保存できます。画質の上限はログイン状態と会員ランクで変わるため、詳細は[ダウンロード方法のガイド](/bilibili-downloader-gui/ja/guides/how-to-download/)の画質の節を参照してください。

## 人気フィードでbilibiliの流行を掴む

検索ボックスが空の状態では、bilibili全体で今人気のある動画が表示されます。特に目的が決まっていないときに「今の流行を保存しておきたい」「おすすめのアニメを探したい」という場合に便利です。

人気フィードもスクロールで自動的に読み込みが続き、キーワード検索と同じようにカードから直接ダウンロードできます。

## ログイン中だけの「あなたへのおすすめ」

Firefox CookieまたはQRコードでbilibiliにログインすると、画面上部に**あなたへのおすすめ**というセクションが表示されます。これはbilibili Web版のホームと同じレコメンドエンジン(視聴傾向に基づく本物のパーソナライズ)で、あなた向けに選ばれた動画を12件、通常より大きなカードで表示します。

各カードにはおすすめの理由(例: 「高点赞量」=高評価が多い)がバッジで付くので、なぜおすすめされたのかも一目でわかります。未ログインのときや取得に失敗したときは、このセクションは表示されません。

ログイン方法の設定手順は[ダウンロード方法のガイド](/bilibili-downloader-gui/ja/guides/how-to-download/)の「ログイン方法」の節で解説しています。

## プレビュー再生で確認してからダウンロード

アプリ内検索の大きな利点が**保存前のプレビュー**です。

- カードにカーソルを合わせる/タップすると、動画の中身が短く再生されます
- 再生できない動画や地域制限のある動画は、専用のメッセージで事前にわかります

「タイトルとサムネイルだけでは判断できない」という動画を、無駄にダウンロードしてしまう前に確認できます。

## 検索履歴と複数キーワードの切り替え

検索したキーワードは履歴として残り、再度の検索や共有のためにURLに反映されます。アプリのURL(または画面共有)を開き直すと、検索の状態から再開できます。複数のキーワードで検索した場合も、それぞれの結果が切り替えられるので「あのキーワードの結果」にすぐ戻れます。

## URL貼り付けとアプリ内検索、どちらを使うべき?

| シーン                                | おすすめの方法                                                                                         |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| すでにブラウザで動画を開いている      | URL貼り付け                                                                                            |
| 何を見るか決まっていない/流行を見たい | アプリ内検索(人気フィード)                                                                             |
| キーワードで探したい                  | アプリ内検索(キーワード検索)                                                                           |
| 自分の好みに合った動画を発見したい    | アプリ内検索(ログイン+あなたへのおすすめ)                                                              |
| 番劇(アニメ)を話数ごとに一括保存      | URL貼り付け+一括ダウンロード([番劇ガイド](/bilibili-downloader-gui/ja/guides/download-bangumi-batch/)) |

どちらの方法でも、ダウンロード後の処理(字幕の埋め込み、MP3抽出、結合など)は共通です。

## よくある質問

### 検索機能を使うのにログインは必要ですか?

いいえ。キーワード検索と人気フィードはログインなしで使えます。「あなたへのおすすめ」のみログインが必要です。

### 検索結果の動画がダウンロードできません

地域制限(中国国内限定)のコンテンツの可能性があります。また、ログイン切れで高画質が選べない場合はログインし直してください。対処の詳細は[よくある質問](/bilibili-downloader-gui/ja/faq/)を参照してください。

### 検索できるのは動画だけですか?

現状は動画(UGC)の検索に対応しています。番劇(アニメ・ドラマ)はURLから一括ダウンロードで保存してください。

## まとめ

Bilibili Downloader GUIのアプリ内検索を使えば、「探す→確認する→保存する」をアプリ1つで完結できます。

- URLコピー不要の**キーワード検索**(サジェスト・無限スクロール対応)
- 流れを掴める**人気フィード**
- ログイン中のみの**あなたへのおすすめ**(推薦理由バッジ付き)
- 保存前に確認できる**プレビュー再生**

まずは[bilibili動画のダウンロード方法まとめ](/bilibili-downloader-gui/ja/guides/how-to-download/)でアプリをインストールして、検索ボックスに好きなキーワードを入れてみてください。
